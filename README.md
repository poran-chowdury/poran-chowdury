I design and develop secure, scalable and high-performance backend applications in **Java and Spring Boot**. For the past four years I've been a core backend engineer of **X4T**, a multi-tenant crypto exchange that handles real customer funds, at **SELISE Digital Platforms** (Dhaka, Bangladesh).

- 🏦 **Money-safe by design:** idempotency keys end to end, owner-checked distributed locks, reconciliation against the source of truth.
- 🔐 **Security and identity:** multi-tenant authentication on Auth0, MFA, SSO and penetration-test remediation.
- ⚙️ **Production ownership:** from API contract to on-call fixes, across Java and Node.js microservices on Kubernetes.
- 🤖 **AI-assisted development:** agentic workflows with Claude Code, with tests and code review as the gate.
- 🌱 **Currently learning:** RAG, LLM agents, evals and MCP with Spring AI.

## What I've built

| Work | What it does |
| --- | --- |
| **Perpetual futures trading** | Taken from first idea to production in about three weeks: a hexagonal core with ~1,700 tests, pre-trade risk checks and reconciliation against the exchange. |
| **Cross-chain trading** | Swaps across Bitcoin, Solana, Tron and EVM chains through pluggable adapters; only routes that will complete are offered. |
| **Retry-safe money movement** | Idempotent transfers, owner-checked Redis locks and terminal-state guards, so a retry never moves money twice. |
| **Multi-tenant identity** | Tenant resolution, per-tenant Auth0, MFA, Google and Apple sign-in, device sessions and signup-abuse controls. |
| **Live transaction tracking** | Every step of a trade or withdrawal pushed to users in real time over Server-Sent Events. |
| **Card issuing (system design)** | A double-entry card ledger, sagas across custody and the card issuer, an outbox and daily reconciliation. |

## Open source

**[Blocks LMT Java Client](https://central.sonatype.com/artifact/com.seliseblocks.core/blocks-lmt-java-client)** on Maven Central: a Spring Boot starter that auto-configures OpenTelemetry tracing and ships logs and spans to Azure Service Bus. It has two release lines (Spring Boot 2.7 and 3).
